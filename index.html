📍 API Endpoints

API Information

Mendapatkan informasi dasar API dan statistik

GET https://tjx578.github.io/datalokasi_maps/api/v1/index.json

Semua Data Lokasi

Mendapatkan semua data lokasi dalam format JSON

GET https://tjx578.github.io/datalokasi_maps/api/v1/data.json

Daftar Kota/Wilayah

Mendapatkan daftar kota dan wilayah yang tersedia

GET https://tjx578.github.io/datalokasi_maps/api/v1/cities.json

Data Per Wilayah

Mendapatkan data lokasi untuk kota/wilayah tertentu

GET https://tjx578.github.io/datalokasi_maps/api/v1/regions/{city_name}.json

Contoh: gianyar_regency.json, denpasar_city.json

CSV Export

Download semua data dalam format CSV

GET https://tjx578.github.io/datalokasi_maps/api/v1/data.csv
