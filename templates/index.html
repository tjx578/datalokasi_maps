🗺️ NaviPro Location Database

API Penyedia Database Lokasi Maps untuk NaviPro

🔗 API Endpoints

Endpoints yang tersedia:

  • GET / - Informasi API
  • GET /health - Status kesehatan server
  • GET /api/locations - Daftar semua lokasi (dengan pagination)
  • GET /api/locations/<city> - Lokasi berdasarkan kota/kabupaten
  • GET /api/search?q=<query> - Pencarian lokasi
  • GET /api/regions - Daftar semua region yang tersedia
  • GET /api/stats - Statistik database
